# Contributing to pdwidgets

pdwidgets is a pure-Python widget toolkit: a `Display`, a `Screen` and about
49 widgets that draw through pydevices and pygraphics. A focused widget test,
a clearer docs example or a fix to a widget's behavior is a good first
contribution. [How pdwidgets works](docs/how-it-works/index.md) explains how
the pieces fit.

## Where things are

| Path | What's there |
|---|---|
| [`lib/pdwidgets/`](lib/pdwidgets/) | The core: `Display`, `Screen`, `Widget`, tasks, themes, focus and utilities. |
| [`lib/pdwidgets/widgets/`](lib/pdwidgets/widgets/) | One module per widget, loaded the first time its name is used. |
| [`lib/pdwidgets/icons/`](lib/pdwidgets/icons/) | Importable bitmap icons, generated by the scripts below. Don't edit by hand. |
| [`lib/pdwidgets/widget-dependencies.md`](lib/pdwidgets/widget-dependencies.md) | Which widgets import which, generated by [`scripts/pdwidgets_widget_deps.py`](scripts/pdwidgets_widget_deps.py). |
| `tests/` | Unit, API, import, rendering and documentation-example checks. |
| `scripts/` | Icon generation, the widget dependency graph and the README screenshot. |
| `tools/` | A render and event micro-benchmark, and a PNG smoke probe. |
| `docs/` | The documentation site's source. |
| [`manifest.py`](manifest.py) | The freeze manifest for [`lib/pdwidgets`](lib/pdwidgets/), for firmware builds. |
| [`pdwidgets.toml`](pdwidgets.toml) | The PyScript gallery's file list. Generated by publishing automation; don't edit it by hand. |
| [`pyproject.toml`](pyproject.toml), `VERSION` | The setuptools metadata and the package version. |

## Run the tests

pdwidgets imports pydevices' `appdev`, `palettes` and `pygraphics`, none of them
installed in the test environment, so the test command puts their sources on
`PYTHONPATH`. From this folder, with a checkout of
[pygraphics](https://github.com/PyDevices/pygraphics) at `$PYGRAPHICS`:

```bash
PYTHONPATH="lib:tests/stubs:../lib:../palettes/lib:$PYGRAPHICS/lib" \
  python -m unittest discover -s tests
ruff check lib tests scripts
```

These are the two checks CI runs. Without the `PYTHONPATH`, discovery fails with
`ModuleNotFoundError: No module named 'events'`.

[`tests/test_doc_examples.py`](tests/test_doc_examples.py) checks every Python block in the README and the
docs against the real package: the names imported, the attributes used and the
keyword arguments passed to widget constructors. It doesn't run the blocks, so
run a changed example yourself.

The benchmark times the render, tick and event paths. It reports relative
numbers, useful for comparing a change with what came before:

```bash
SDL_VIDEODRIVER=dummy SDL_AUDIODRIVER=dummy python tools/pdwidgets_bench.py
```

## Widget conventions

- A `Label` takes its text as `value=` and a `Button` as `label=`. There is no
  `text=` and no alias for a class name.
- `radius` is stored on every `Widget`, default 0. Rounded faces (`Button`,
  `Card`, `Chip`) read it; the base `draw()` fill ignores it.
- `widget.remove()` detaches a widget from its parent and `widget.clear()`
  removes all its children. `widget.hide()` or `widget.visible = False` hides it
  without detaching.
- `add_event_cb` calls `callback(data_or_sender, event)`, with the data first and
  the event second. The data defaults to the widget that registered the callback.
- Keep custom widgets on the normal event and invalidation path instead of
  adding a render loop.

Regenerate the dependency graph after editing widgets:

```bash
python scripts/pdwidgets_widget_deps.py
```

## Regenerate the icons

Runtime icons are importable Python modules under [`lib/pdwidgets/icons/`](lib/pdwidgets/icons/), with
no binary files. To regenerate them:

```bash
# 1) Optional: regenerate the mono .pbm and color .bmp from Material Design
python scripts/assets_generate_pdwidgets_icons.py
python scripts/assets_make_color_icons.py
# 2) Convert the binaries to .py modules (BITMAP = bytearray). This needs a
#    pygraphics checkout beside the repository, because FrameBuffer.export is
#    pure-Python only and isn't in the published wheel.
python scripts/assets_icons_to_py.py --delete-binaries
# Optional: bulk dump into assets/icons/
python scripts/assets_convert_md_png_to_pbm.py
```

## Redraw the README picture

[`docs/images/pdwidgets.png`](docs/images/pdwidgets.png) is the README example after three clicks. Redraw it
on a machine with `pydevices-desktop` and Pillow installed:

```bash
SDL_VIDEODRIVER=dummy PYTHONPATH=lib python scripts/generate_readme_screenshot.py
```

## Build the docs

```bash
pip install -r docs/requirements.txt
sphinx-build -W --keep-going -b html docs _site
```

Read the Docs builds the same site from [`.readthedocs.yaml`](.readthedocs.yaml), with warnings as
errors. The API pages are generated from the docstrings when you build.

## Release

pdwidgets has its own version, in `VERSION`, apart from the pydevices release.
A pull request that changes `VERSION` and adds the matching section to
`CHANGELOG.md` tags `pdwidgets-vX.Y.Z` when it merges, and the pydevices release
chain publishes `pydevices-pdwidgets` to TestPyPI. The import name and the mip
package name stay `pdwidgets`.
