# AGENTS.md

- Run from `palettes/`: `PYTHONPATH=lib python3 -m unittest discover -s tests`, then `ruff check lib tests scripts`. These are the two checks CI runs.
- `palettes` has its own version in `VERSION`, apart from the pydevices release. A merged change to `VERSION` and `CHANGELOG.md` tags `palettes-vX.Y.Z` and publishes `pydevices-palettes`; the import and mip name stay `palettes`.
- `lib/palettes/_*.py` is generated or static color data, and [`palettes.toml`](palettes.toml) is generated by publishing automation. Don't edit either by hand.
- Docstrings use Google style with no Sphinx roles (no `:class:`); CI fails on one.
- More in [CONTRIBUTING.md](CONTRIBUTING.md).
- Examples follow the style in the [repo's AGENTS.md](../AGENTS.md): REUSE licence header, a docstring ending `Needs:`, `Run it:`, `Tested on:`, a settings block, a comment above each step, pygraphics rather than `framebuf`.
