# Run in the browser

palettes needs only Python, so it runs in a browser with PyScript or Pyodide.
These pages load it with `micropip` and draw with it:

- [palettes_demo](https://pydevices.github.io/gallery/pyscript/pyodide.html?modules=palettes_demo&deps=pydevices-palettes,pydevices-pygraphics): every palette family and color bar.
- [feathers](https://pydevices.github.io/gallery/pyscript/pyodide.html?modules=feathers&deps=pydevices-palettes,pydevices-pygraphics): generative curves colored from the wheel.
- [rotations](https://pydevices.github.io/gallery/pyscript/pyodide.html?modules=rotations&deps=pydevices-palettes,pydevices-pygraphics): palette cycling and sweeps.
- [scroll](https://pydevices.github.io/gallery/pyscript/pyodide.html?modules=scroll&deps=pydevices-palettes,pydevices-pygraphics): a scrolling gradient.

To use palettes in your own page, install it as in
[Install](../get-started/install.md#in-the-browser). The wheel's name is
`pydevices-palettes` and the module you import is `palettes`.
