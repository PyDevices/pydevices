# Contributing to palettes

palettes is a small, dependency-free package: one factory, `get_palette()`, and
four palette families behind it. A docstring fix, a clearer example or a
regression test for a documented color format is a good first contribution.
[How palettes works](docs/how-it-works/index.md) traces one lookup through the
code.

## Where things are

| Path | What's there |
|---|---|
| [`lib/palettes/__init__.py`](lib/palettes/__init__.py) | The factory, the `Palette` and `MappedPalette` base classes, the ordered Windows 16 table and the shared conversion and name behavior. |
| [`lib/palettes/wheel.py`](lib/palettes/wheel.py) | The classic wheel and fixed-saturation HSV ramps. |
| [`lib/palettes/cube.py`](lib/palettes/cube.py) | RGB cubes with 2 to 5 steps per edge. |
| [`lib/palettes/material_design.py`](lib/palettes/material_design.py) | The Material Design palette, backed by the generated RGB table. |
| `lib/palettes/_*.py` | Generated or static color and name data, not alternate public APIs. |
| `tests/` | An import smoke test, plus contracts for depth, index and name order and cube size. |
| `docs/` | The documentation site's source. |
| [`scripts/generate_palette_screenshots.py`](scripts/generate_palette_screenshots.py) | Redraws the images under [`docs/images`](docs/images/). |
| `manifest.py` | The freeze manifest for [`lib/palettes`](lib/palettes/), for MicroPython and CircuitPython firmware builds. |
| `palettes.toml` | The PyScript gallery's file list. Generated by publishing automation; don't edit it by hand. |
| `pyproject.toml`, `VERSION` | The setuptools metadata and the package version. |

## Run the tests

From this folder:

```bash
pip install -e .                        # or set PYTHONPATH=lib
PYTHONPATH=lib python3 -m unittest discover -s tests
ruff check lib tests scripts
```

These are the two checks CI runs. If a change touches a color depth, a name
table, index order, cube size or the factory, add or update a focused test
before relying on an image as evidence.

Docstrings use Google style with no Sphinx roles (no `:class:` or `:meth:`);
cross-reference with a single backtick, as in `` `Name <path>` ``. CI fails on a
role.

## Build the docs

```bash
pip install -r docs/requirements.txt
sphinx-build -W --keep-going -b html docs _site
```

Read the Docs builds the same site from `.readthedocs.yaml`, with warnings as
errors. The API pages are generated from the docstrings when you build.

## Release

palettes has its own version, in `VERSION`, apart from the pydevices release.
A pull request that changes `VERSION` and adds the matching section to
`CHANGELOG.md` tags `palettes-vX.Y.Z` when it merges, and the pydevices release
chain publishes `pydevices-palettes` to TestPyPI. The import name and the mip
package name stay `palettes`.
