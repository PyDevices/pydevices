# AGENTS.md

- Run from `packages/iconkit/`: `PYTHONPATH=lib python3 -m unittest discover -s tests`, then `ruff check lib tests tools`. The generator's tests need Pillow, and the MicroPython half of the contract needs a unix build: set `PYDEVICES_MICROPYTHON` to it, and `PYDEVICES_REQUIRE_MICROPYTHON=1` to fail instead of skip.
- `iconkit` has its own version in `VERSION`, apart from the pydevices release. A merged change to `VERSION` and `CHANGELOG.md` tags `iconkit-vX.Y.Z` and publishes `omnipython-iconkit`; the import and mip name stay `iconkit`.
- `lib/iconkit/_a8_24.py` and `_a8_48.py` are generated by `tools/make_icons.py`: change `icons_24.txt` or `icons_48.txt` and regenerate, never edit them by hand. The generator takes the Material Design Icons checkout as an argument and names no local path; keep it that way.
- Nothing falls back silently. A wrong name or size raises `ValueError` that says what to do. The masks stay frozen A8 bytes, and the two shipped sets stay at or under 72 KB each.
- `docs/reference/icons.md` and its two PNGs are rebuilt by `tools/icon_sheets.py`.
